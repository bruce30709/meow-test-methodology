## 一、《獸醫師法》與寵物食品宣傳合規原則

本站嚴格遵守台灣《獸醫師法》與農業部寵物食品標示宣傳規範：

- 全面排除任何涉及「疾病診斷、預防、治療、軟便率、嘔吐或生理症狀」之指標與統計。
- 100% 專注於**公開包裝保證分析之乾物比碳水化合物（DMB Carbs%）數學換算、物理顆粒尺寸（mm）、貓砂物理表現、挑嘴貓適口性與每貓每日飼養成本**。
- 獸醫處方日糧（如皇家 LP34）依法獨立隔離，不納入一般排行亦不提供商業導購。
- 所有排序公式與權重 100% 公開，**廠商無法付費影響排名**。

## 二、實測與評比維度

### 1. 貓砂標準實測維度（5 大物理指標）

| 指標 | 評測與紀錄方法 |
|---|---|
| **低粉塵** | 於深黑卡紙上定距倒砂，強光側拍灰塵落點與懸浮量，換算 1–5 分（5 最無塵） |
| **結團力** | 定量注入 20ml 水分，靜置 60 秒夾取並施壓測試碎裂度（1–5 分） |
| **防帶砂** | 記錄出盆後肉球夾帶落砂量與周圍地板沙漠化程度（1–5 分） |
| **除臭力** | 第 3 天與第 7 天使用氨氣感測與居家盲測雙重驗證（1–5 分） |
| **貓咪接受度** | 統計貓咪換砂後正常進盆如廁、無排斥憋尿之比例 |

### 2. 貓飼料合規實測維度（物理規格 ＆ 乾物比營養換算）

| 指標 | 計算與評測方法 |
|---|---|
| **乾物比碳水（DMB%）** | 先算無氮浸出物 `NFE = 100% - (粗蛋白 + 粗脂肪 + 粗纖維 + 粗灰分 + 水分)`，再以 `DMB% = NFE ÷ (100% - 水分)` 還原去除水分後的真實碳水占比 |
| **物理顆粒尺寸（mm）** | 實測顆粒直徑、厚度與幾何形狀，評估小嘴貓與吞嚥習慣契合度 |
| **挑嘴貓適口性** | 彙整社群與實測家庭之開袋聞香反應與主動清碗比例（1–5 分） |
| **每貓每日伙食成本** | 依成貓每日標準熱量攝取克數與大包裝實購均價換算單貓每日開銷（NT$/日） |

## 三、排行綜合分數公式與權重（貝氏平滑）

為避免極少數極端評價拉偏排行，所有綜合評分皆採用**貝氏平滑平均（Bayesian Smoothing，常數 `C = 10`）**：

```text
貝氏平滑分數 = (10 × 品類平均 + Σ 權重 × 分數) ÷ (10 + Σ 權重)
```

| 貓砂綜合評分維度 | 佔比 | 貓飼料綜合評分維度 | 佔比 |
|---|---:|---|---:|
| 真實回購率 | 30% | 真實回購率 | 35% |
| 每貓每日耗材成本（愈低愈高分） | 25% | 挑嘴貓適口性表現 | 30% |
| 低粉塵表現 | 20% | 每貓每日伙食成本優勢 | 20% |
| 長效除臭力 | 15% | 低碳水化合物優勢（DMB%） | 15% |
| 貓咪接受度 | 10% | 處方日糧（依法隔離不排名） | — |
